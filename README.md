# MiniWinLoss

Shows your win-loss and percentages for rated pvp on the conquest frame.

This provides a quick at-a-glance view of your win to loss ratios across all rated brackets (2v2, 3v3, solo shuffle, blitz, and rated battlegrounds).

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
